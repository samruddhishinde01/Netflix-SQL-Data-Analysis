# Netflix SQL Data Analysis

##  Project Overview

This project focuses on analyzing a Netflix dataset using SQL to identify useful patterns and insights about movies and TV shows.

The project demonstrates practical SQL skills such as filtering, grouping, aggregation, sorting, joins, and subqueries to answer real-world data analysis questions.

##  Dataset

The dataset contains information about Netflix movies and TV shows, including:

- Title
- show_id
- Type
- Director
- Language
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Number of seasons
- Ratings
- Budget
- Revenue
- Popularity scor

##  Analysis Performed

The project answers different questions related to the Netflix dataset, such as:

- What is the total number of movies and TV shows?
- How many movies and TV shows are available?
- Which ratings are most common?
- Which countries have the highest number of titles?
- How has the number of titles changed over the years?
- Which genres are most common?
- What are the longest movies?
- Which directors have the most titles?
- What type of content is more common on Netflix?
